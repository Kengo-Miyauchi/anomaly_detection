## Prefix Tuning for LLMs
This repository provides a framework for prefix tuning of large language models (LLMs) using PyTorch and Hugging Face's Transformers library. It allows users to fine-tune LLMs by learning a set of trainable prefix tokens that can be prepended to the input sequence, enabling efficient adaptation to specific tasks without modifying the entire model.

## Requirements
Python >= 3.7

```bash
pip install -r requirements.txt
```
